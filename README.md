# ПЕКАРНЯ DAG — сайт с заказами и панелью администратора

Сайт для клиентов (`/`) и закрытая панель (`/admin`). Данные хранятся в Supabase, хостинг на Vercel. Сборка не нужна: это обычные HTML, CSS и JS.

```
index.html            витрина для клиентов
admin.html            панель администратора (адрес /admin)
assets/css/style.css  весь дизайн
assets/js/config.js   ВАШИ настройки (ключи Supabase, валюта, контакты)
assets/js/shop.js     логика витрины
assets/js/admin.js    логика панели
supabase/schema.sql   таблицы, правила безопасности, хранилище фото
vercel.json           настройки хостинга
```

## Шаг 1. Проект в Supabase

1. Зайдите на supabase.com, создайте проект (New project), придумайте пароль базы и сохраните его.
2. Откройте **SQL Editor → New query**, вставьте весь файл `supabase/schema.sql` и нажмите **Run**. Должно появиться «Success».

## Шаг 2. Ключи в config.js

В Supabase откройте **Project Settings → API** и скопируйте:
- **Project URL** в `SUPABASE_URL`
- ключ **anon / publishable** в `SUPABASE_ANON_KEY`

Ключ `service_role` не вставляйте никуда в сайт. Ключ anon показывать в браузере безопасно: данные защищены правилами в базе.

Там же можно указать валюту, телефон, адрес и часы работы. Пустые поля не показываются.

## Шаг 3. Создайте администратора

1. В Supabase: **Authentication → Users → Add user → Create new user**. Введите свою почту и сильный пароль, поставьте галочку **Auto Confirm User**.
2. В **SQL Editor** выполните (подставьте свою почту):

```sql
insert into public.admins (user_id)
select id from auth.users where email = 'ВАША_ПОЧТА@example.com';
```

3. Запретите регистрацию посторонних: **Authentication → Sign In / Providers** (в старых версиях: Settings), выключите **Allow new users to sign up**.

## Шаг 4. Проверка на своём компьютере (по желанию)

Откройте папку проекта в VS Code с расширением Live Server или выполните `npx serve` в папке проекта. Откройте сайт, затем `/admin`, войдите и добавьте первую позицию меню.

## Шаг 5. Публикация на Vercel

1. Создайте репозиторий на GitHub и загрузите туда содержимое папки проекта.
2. На vercel.com: **Add New → Project**, выберите репозиторий. **Framework Preset: Other**, команду сборки и Output Directory оставьте пустыми. Нажмите **Deploy**.
3. Через минуту сайт будет по адресу вида `ваш-проект.vercel.app`. Панель: `ваш-проект.vercel.app/admin`.
4. В Supabase: **Authentication → URL Configuration**, в **Site URL** впишите адрес вашего сайта на Vercel.

Свой домен подключается в Vercel: **Project → Settings → Domains**.

## Как устроена защита админки

- Вход по почте и паролю через Supabase Auth.
- После входа база проверяет, есть ли ваш пользователь в таблице `admins` (функция `is_admin()`). Если нет, вас тут же разлогинит.
- Это не просто скрытая страница: **правила RLS в базе** не отдают чужим ни заказы, ни управление меню, даже если кто-то пошлёт запрос в обход сайта.
- Заказы создаёт функция `create_order()`. Цены и наличие она берёт из базы, поэтому подменить цену в браузере нельзя. Есть лимит: не больше 5 заказов с одного телефона за 10 минут.
- Клиент видит статус только своих заказов: идентификатор заказа знает лишь его устройство.
- Таблица `admins` закрыта для всех через API.

Что стоит сделать дополнительно:
- Сильный и уникальный пароль админа, включите двухфакторную защиту на аккаунте Supabase и GitHub.
- Если хотите, чтобы вход в панель был только у вас, оставьте регистрацию выключенной (шаг 3).

## Частые вопросы

**Заказ не отправляется, ошибка про функцию.** Проверьте, что `schema.sql` выполнился целиком без ошибок.

**В панели нет новых заказов в реальном времени.** В Supabase проверьте **Database → Replication**: таблицы `orders` и `products` должны быть в публикации `supabase_realtime`. Скрипт делает это сам.

**Звук уведомления не играет.** Браузер включает звук только после первого клика по странице. Кликните в любом месте панели один раз.
